Parole di Reparto

Import a CSV file

Columns: italiano, english, category, example. Only the Italian is required. A header row is fine (Italian or English names), and commas, semicolons or tabs all work, so a file saved from Excel, Numbers or Google Sheets opens as it is.

Paste many at once

One card per line: italiano | english | category | example. Category and example are optional. Categories: lab, materials, quality, office, life.

Impostazioni

Words you've already started don't count; they come back when they're due.

Backup and move to another phone

Your cards live only on this phone. Save a CSV file now and then (to Files or iCloud). To restore, import it with “Import a CSV file”. Learning progress is not included.
